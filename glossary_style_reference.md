# Образец стиля терминов глоссария

Этот файл читают агенты judge и arbiter перед вынесением вердикта. Он задаёт
ЕДИНЫЙ стиль русских терминов тайтла. Пополняй раздел «Принятые решения»
по мере судейства — агентам нужны живые примеры уже принятых вариантов.

## Общие правила

- **Имена собственные** — практическая транскрипция по Палладию (пиньинь →
  кириллица): 林 → Линь, 張偉 → Чжан Вэй. Без апострофов и дефисов внутри слога.
- **Говорящие имена и прозвища** переводятся по смыслу, если смысл важен для
  сюжета, и транскрибируются, если это обычное имя.
- **Названия видов, юнитов, рас** — существительное, а не описательный оборот:
  «Летун», а не «Летающее существо». С заглавной, если в тексте это имя
  собственное вида/юнита; со строчной — если нарицательное.
- **Род** указывается для каждого одушевлённого термина и определяет
  согласование во всём корпусе. Не гадай: смотри на контекст оригинала.
- **Один китайский термин — один русский вариант.** Синонимы допустимы только
  если явно задокументированы в `glossary_overrides.json` (allow_shared_ru).
- **Разные китайские термины не должны сходиться в один русский**, кроме
  задокументированных синонимов — иначе читатель не различит сущности.
- **Не тащи грамматические обрывки.** Кандидат вида «的力量», «了一» — не термин;
  вердикт `reject`.
- **Бытовое слово не термин.** Если иероглифы в большинстве контекстов —
  обычная лексика («存在», «生物»), термин отклоняется: правило замены по
  такому слову вандалит текст.
